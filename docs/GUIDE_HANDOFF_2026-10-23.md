2. 로컬 변경부터 확인하고 보존한다.
   ```powershell
   git status --short
   git stash list
   ```

## 1. /guide란

팀 프로젝트(기업가치 훼손위험 탐지)를 **실제 데이터로 처음부터 끝까지 따라가며 이해하는 읽기 전용 사이트**. 기존 대시보드(8770)와 같은 서버가 `/guide`로 서빙한다. 기존 화면·API·원본 데이터는 건드리지 않는다.

- 대상 독자: 사용자 본인(프로젝트 이해용). 팀 공유 전 단계. **드라이브에 올리지 않는다.**
- 원칙: 단정하지 않는 문구(AI 티 나는 장식 문구 금지), 시각화·애니메이션 중심, 한계는 숨기지 않고 표시.

## 2. 프로젝트 이해(사용자와 합의한 정정본) — 사이트 문구의 기준

- 대주제: 사용자에게 "틀렸다"고 증명하는 시스템이 **아니다.** 손실 중인 종목의 보유 이유를 **근거로 점검**한다. 가격 하락·재무 악화만으로 가치 훼손을 확정하지 않고, 근거가 부족하면 **판단 유보**.
- 흐름: 입력(종목·산 날·보유 이유) → 탐지 → 분석 → 증거 → 반박.
- 모델 3개: 서서히 모델(가격 탐지 CUSUM + 재무 F-Score·DuPont·Ohlson), 급락 모델, 반박 모델. **급락·반박은 세부가 미정이라 사이트에 역할만** 넣었다("세부 방법 · 미정").
- 2014는 표본 선정 기준 연도, 2015~2019는 **과거 사례 재현**. "가상 포트폴리오 vs 소비자 포트폴리오" 비교가 아니라 **같은 종목의 산 날 vs 지금** 비교(ΔX = X_now − X_buy).
- 점수 0~9는 F-Score만. 세 모형 변화량을 각각 0~3점으로 바꿔 통합 판정. **절대 점수가 아니라 변화량**으로 본다. 경계값·r=8.5%는 검증 전 가설.
- 반박 모델은 서서히/급락 모델을 반박하지 않는다. 두 모델이 만든 **증거로 사용자의 보유 이유(Toulmin: 주장·근거·전제)를 시험**하고 지지·반박·전제 약화·판단 유보로 판정한다.

## 4. 실행

필요: Python 3 + `pandas`, `numpy` (생성기). 서버는 표준 라이브러리만 쓴다.

```powershell
# 1) data.json 생성 (폴더 스캔 때문에 몇 분)
python build_guide_data.py --drive "<드라이브>\skku_fds_main"
# 폴더 목록 재사용(빠름): --reuse-files

# 2) 기존 방식으로 서버 실행 (인계서 U절). 이미 켜져 있으면 server.py 변경 반영을 위해 이 FDS 서버만 재시작
#    http://127.0.0.1:8770/guide
```

- 서서히 모델 코드는 드라이브의 `모델개발/서서히모델_v0`(예전 `서서히모델_v0`)를 자동 탐색해 import한다.
- 드라이브 쪽 읽기 전용: 생성기는 `__pycache__` 등을 드라이브에 만들지 않는다(`PYTHONDONTWRITEBYTECODE=1`을 쓰면 더 안전). 드라이브에 쓰지 않는다.

- **큰 그림(홈)**: 질문 헤드라인, 5단계 흐름(입력·탐지·분석·증거·반박, 상태 칩), 사례 한 줄(보유 이유 → 증거 → 반박 설계), "점수가 아니라 변화", 11종목 호라이즌, 산 날 손잡이를 끄는 분석 무대(+ 산 날별 판정 띠, 사업보고서 주석).
- **모델**: 서서히 모델(F-Score·DuPont·Ohlson·가격 탐지 CUSUM 시연), 급락·반박은 역할 도식만. 시간 스크러버로 "그날 공개된 값" 재생. DuPont 아래 OpROA 폭포.

- **데이터**: 8단계 파이프라인(수치는 드라이브 검증 JSON에서 읽음), 공시 시점 타임라인, 드라이브 탐색기.
- **현황**: 7주 일정, 영역별 진행(대략값), D01~D10, 최근 바뀐 자료.
- 기본 예시 종목: 비에이치아이(083650), 2017-06-30 → 2019-12-30 (가격 −72%, F 7→4, 판정 훼손 우려, 가격 단위 점프 없음).

## 6. 알려진 한계·주의

- 가격은 **조정 여부 미확인 원본 종가**. 가격만 크게 뛰고 시가총액은 그대로인 날은 "가격 단위 변경(액면분할·병합) 의심"으로 표시한다. 현진소재·대창솔루션이 해당. 호라이즌은 그날을 시가총액 변화율로 보정(증자·감자는 반영 못 함).
- 점수·판정은 `서서히모델_v0`가 계산한 값을 그대로 쓴다. JS로 재구현하지 않는다(민감도 슬라이더를 넣지 않은 이유).
- 가격 탐지 시연은 시장·업종 조정이 없는 단순 버전. 급락 임계값 시연은 정해진 게 없어 뺐다.
- 담당자 표기는 사이트에서 모두 제거했다(요청). 드라이브 폴더명에 `(지해)` `(나현)`이 있어 경로 표시에는 남는다.
- 드라이브 링크는 전부 루트 폴더(`url.txt`)로 연결. 폴더·파일별 링크는 `drive_links.json`의 `paths`에 `"경로": "URL"`로 넣고 `--reuse-files`로 재생성하면 적용. `.gdoc`/`.gsheet`는 로컬에서 읽히지 않아 링크를 자동으로 얻을 수 없다.
- 브라우저 패널이 숨겨져 있으면 CSS 애니메이션이 멈춘다. 애니메이션 검증은 실제로 보이는 창에서.
- 모바일은 가로 넘침만 확인했다. 실사용 점검 필요.
- 호라이즌 첫 렌더가 220KB 문자열이라 산 날을 빠르게 끌면 느낄 수 있다(변경 시점에만 다시 그림).

- 드라이브 트리맵, 민감도 슬라이더, F-Score·Ohlson 추적(지금은 DuPont만).
